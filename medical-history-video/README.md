# 30 秒医学简史（竖屏短视频）

成片：[`medical-history.mp4`](medical-history.mp4)，1080×1920，30fps，30 秒，H.264 + AAC。

## 内容

| 时间 | 画面 |
| --- | --- |
| 0–2.2s | 片头：「30秒 看完2400年医学史」 |
| 2.2–25.2s | 10 个里程碑，每个 2.3 秒：年份滚动 + 线稿图标 + 标题 |
| 25.2–30s | 片尾：全球人均预期寿命 29 岁 → 73 岁（1800–2023）+「下一个突破，会是什么？」 |

里程碑：约前400 希波克拉底 · 约200 张仲景《伤寒杂病论》 · 1543 维萨里《人体构造》 · 1796 詹纳牛痘接种 ·
1846 乙醚麻醉公开演示 · 1895 伦琴发现X射线 · 1928 弗莱明发现青霉素 · 1953 DNA双螺旋 ·
1972 屠呦呦团队发现青蒿素 · 2020 mRNA疫苗获批使用。

寿命数据取自 Our World in Data 的全球人均预期寿命（1800 年约 28.5 岁，2023 年约 73.2 岁）；曲线中间点是按整点近似的趋势。

画面贯穿一条心电图，每到一个里程碑心跳一次；音轨里的心跳声、监护仪“嘀”声与之同步。所有图形和声音都由代码生成，没有使用第三方素材。

## 重新生成

依赖：Node.js + Playwright（Chromium）、Python 3（`numpy`、`imageio-ffmpeg`）。

```bash
./fetch-fonts.sh          # 下载思源黑体/宋体子集（SIL OFL）到 fonts/
python3 audio.py          # 合成 audio.wav
node render.js            # 逐帧渲染并编码 → medical-history.mp4
node render.js --still 3,12.5   # 只导出指定时间点的静帧到 frames/，用于预览
```

改文案或时间轴：编辑 `index.html` 里的 `MS` 数组和 `T0` / `D`。如果改了时间，`audio.py` 顶部的同名常量也要一起改。
