# 一、决定元素强弱的三项

**强度 = 丰度 × 性质上限 × 开发难度的倒数**

其中**开发难度是最被低估、也最决定个人命运的一项**。

---

# 二、开发难度由性质决定

从"生成亲和"到"能靠它干活"，中间隔着多少投入，由六项性质决定：

| 性质 | 容易开发 | 难以开发 |
|---|---|---|
| **自然形态** | 成块、成锭、成器 | 粉末、碎屑、气体 |
| **质量与惯性** | 重，托起后稳定 | 轻，风一吹就散 |
| **结合状态** | 自然界多有游离态 | 几乎全为化合物，须拆键 |
| **可辨识度** | 肉眼可见、可触 | 无色无形，不知在哪 |
| **成形能力** | 能做成形状并保持 | 一松手就塌 |
| **单位回报** | 同样一份能量，做的功更有用 | 费了半天只挪动一点 |

**关键推论**：开发难度高的元素，练习周期长、能量石消耗大。
而练习要烧石头，石头要钱——**所以事实上只有富人练得起难开发的元素**。
穷人生成了难开发的亲和，约等于什么都没生成。

# 三、元素档位

## 【主力】开发易、回报高、丰度高

**铁** —— 矿石遍地，工坊成熟，成块可托、可承力、可成形。
练半年就能进工坊干活。人数最多，也最有用。铁匠是体面人。

**铜** —— 易成线材，导热导电（虽无人知道原理，只知"能传热、能引雷"）。
比铁贵，但用途明确。工坊与商会的常客。

## 【命脉】本身不起眼，但停了它整个工坊就停

**硅** —— 砂、石英、陶瓷、玻璃。成形需高温，开发难度中上。
但耐火材料、观察件、隔离件都靠它。握在几家世家手里，手艺父子相传。
本地人叫"石头的"。

**硫** —— 冶炼脱硫、药材。产量有限，用途敏感。**这个时代没有火药**：硝、硫、炭拌在一起能炸，没人想到过。
凡涉硫者多有官方登记。

## 【富而不强】开发易，但料太少

**金、银** —— 质软、块状、极易操控，练起来最快。
可惜一辈子摸到的总量有限。
但他们**买得起任何等级的能量石**，也买得通任何人。
战场上未必强，世上的事却多半绕不开他们。

## 【无形】开发极难，成了便无可替代

**氧、氮** —— 无色无形，极度分散，无从下手。
十个生成气体亲和的人，九个一辈子练不出名堂。
练成的那一个，能供反应、能改变气氛条件、能在封闭空间里救人。
稀少、被争抢、且**几乎必须与人合作才能发挥**。

**氯** —— 与氧同属难开发，且有毒。自然界没有现成的氯，要从盐里拆，极烧石头，散修烧不起。
早年替皇家打地盘，**一人足以屠城**（见第九节）。如今聚成一派，由大统领统领。

## 【废才】性质优秀，但这个时代提炼不出料

**铝** —— 自然界几乎没有游离态，全是化合物，拆键代价高到荒唐。
铝亲和者在这个时代是笑柄：一身本事，无料可用。
本地贬称"**摸泥的**"：手底下满地答应（泥、土、窑黏土），一撮托不起，说不上摸的是什么（第二十三章林砚回忆煤场笑话）。
*（注：这条线是宝藏。一旦有人知道怎么弄出料来，
他们会在一夜之间从笑柄变成战力。林砚知道。）*

## 【看不到头】开发难度最高

**碳** —— 丰度极高，煤场遍地都是。
但它几乎全以粉末、碎屑、松散块状存在：轻、散、易混杂、易被风带走、
难托起、更难成形。同样练一年，铁亲和者已能搬动整块铁料，
碳亲和者还是只能让一撮黑末飘在掌心。

**社会的判断很朴素：碳能力"没出息"。**
不是因为碳不值钱，是因为练它看不到头。
没人愿意把有限的能量石花在一条看不见回报的路上。

**碳亲和者唯一被社会承认的用处：给燃料定等级。**
煤越纯，里面真正的煤越多，对碳亲和者"答应"得越痛快；
劣煤里掺着水、泥、烧不着的石头，把能用的部分裹在中间，
伸手探去几乎没有回应。
普通人分煤只能看光泽、掂分量、闻烟味，最准的办法是烧一炉试试；
碳亲和者伸手一探就分得出来。
本地人把这叫煤的"性子"：好煤性子急，劣煤性子闷。

这门手艺有用，但出不了煤场。碳亲和者一辈子的出路，
就是在煤场、炭窑、锅炉房给燃料定等。

**后果**：这个世界对碳的形态、结构、用途，几乎没有任何积累。
全世界都绕开了这条路。

# 四、由此产生的社会分层

| 层 | 谁 | 处境 |
|---|---|---|
| **顶层** | 金银那几家，及他们拿钱堆起来的皇家 | 石头不限量，想练什么练什么 |
| **顶层之外** | 氯的（大统领一派） | 名义上是皇家的兵，实际皇家的令出不了宫门 |
| **上层** | 铁、铜、硅、硫的世家与工坊 | 有稳定石头配给，走成熟路径 |
| **中层** | 有师承的普通能力者 | 石头按份额领，练到够用为止 |
| **底层** | 无师无派者 | 石头靠自己买，练一次算一次 |
| **不入流** | 难开发元素的穷人 | 生成了亲和，也等于没生成 |

**林砚在最后一格。**

碳亲和 + 无户籍 + 无师承 + 无钱。
煤场管工也是碳亲和，靠给煤定等当上了管工。
他把手悬在车上停一停，便说上、中、下，他说什么价就是什么价——
**那已经是这个世界里碳亲和者的天花板了**。
一个煤场只需要一个会探煤的人，所以管工不会欢迎第二个。
他说"我又没打赢过"，不是谦虚，是行业现实。

# 五、反转的种子

碳恰恰是**形态最多、用途最广**的元素。

同一种东西，可以是煤、是炭、是石墨、是金刚石，
可以吸附、可以润滑、可以导电、可以耐火、可以参与炼铁。

**只是没有人知道那些东西是同一种东西。**

这个世界放弃碳，不是因为判断错了——按他们掌握的信息，
碳确实看不到头。他们的推理是对的，**只是信息不完整**（见 I1）。

同样是探煤，管工知道"这堆答应得痛快"，林砚知道为什么——
里面真正的煤多，杂质少。解释看着不值钱，但它能推广：
管工只会探煤，林砚会想到任何含碳的东西都能这样探——
炉渣、焦炭，乃至铁。铁的软硬脆韧很大程度取决于含碳多少，
而这个世界没人把"煤好不好"和"铁好不好"当成同一件事。

林砚的优势不是"发现碳很强"，
而是知道**碳的难用恰恰来自形态多变**，
而形态多变，在知道怎么用的人手里就是最大的优势。

# 六、主场优势（承接现场判定）

主场不是战力加成，是五项条件叠加后的现场优势：

- **来源丰度** —— 附近有多少，能否持续补给
- **形态与状态** —— 固液气、粉末、薄膜、化合物，可操控方式不同
- **可达性** —— 裸露流动的易取；深埋、密封、被包覆的阻力高
- **纯度与结合** —— 游离的好用；稳定成键的拆不起
- **地形与补给** —— 风向、坡度、积水、炉膛、通风、运输线

**主场可以被夺走**：抽干水源、封闭通风、覆盖矿粉、改变温度、
切断运输线、污染原料、逼对方离开储备区。

**临时主场**：提前勘探与布置可以把普通地点改造成有限主场，
但这属于准备与后勤，需支付运输、保护、分配、损耗，
不等于凭空扩大能力。

# 七、能量石经济（要点）

- 能量石是这个世界的燃料、货币与门槛，用于锻造、开矿、建造
- 按颜色分级定价，赤黄级是散工与小工坊的日常消耗品
- 紫石是传世之物，一块可换一座宅子
- **练习也要烧石头** —— 这是阶层固化的真正机制
- 石商、矿场、运石车、锅炉房构成完整产业链
- 透明石（红外级）被视为废料，论斤称卖，填炉膛，丢废石堆

# 八、本地人的叫法

- 本地人按**看得见的东西**叫能力：铁的、铜的、碳的、金的银的、石头的
- 氯的名号响亮，人人闻之色变
- 看不见的、没见过的，没有叫法：只会说"炸的""鬼火""水着火了"
- 林砚心里叫硅、叫氢、叫磷、叫钠——**按外观和按结构，两套叫法**
- 碳亲和者探煤的那一下，本地人叫煤的"性子"：急、闷；碳亲和者说它"答应"得痛快不痛快

# 九、氯的与天下

- **氯有多狠**：青石城，城墙三丈，城里铁的上千。皇家派一个氯的，站在城北上风坡上，一夜，
  雾漫过城墙，灌进街、井、地窖；躲进地窖的一个没上来。**皇家的地，一多半是这么来的。一个人，一座城**
- **皇家**：是金银那几家拿钱一年一年堆起来的，是他们最大的一笔资本，也是门面。
  他们最怕氯的，把氯的拆散；可地还要打，就封了一个将军来管——**氯的大统领**
- 大统领替皇家办事，石头、盐要多少有多少；拆散的氯的重新聚到他手下，如今明着来
- 皇家的令出不了宫门，但**面上态度没变**：照旧称他大统领，年年加封，赏从皇家库里出
- 氯的作恶多端：强占、灭门、街上看谁不顺眼就放一口雾。皇家、金银、铁，面上一个字不说，咬着牙忍——
  忍，是因为头顶悬着那团雾
- **挡氯的法子是氯的生死线**：雾一旦不再要命，底下的积怨就压不住
- 铁的散成七八家（近战流、千剑流最大），想拧成一股跟大统领掰手腕
- 拆盐拆出氯，剩下的一半是钠。氯的拆了这么多年盐，这一半去了哪儿——林砚的疑问，作者心里有数

# 十、红令

- 大统领亲手用印。令分三等：**白的拿人，黄的抄家，红的只要命**
- 红纸，红得发暗；墨重；印泥黄里带绿。贴城门、贴驿站
- 这些年发过四道，没有一个活过两个月。**红令不撤，人死了才撤**
- 赏由皇家库出。林砚那一道：紫石一块，黄金万两；取首级验看；**藏匿者同罪**
- （备用）东门挂号册子若落到氯的手里，红令可加上"其人姓林，名砚。东门挂号，具保人：东城煤场管工"
- 接令的人彼此传话：谁用了什么招、在哪儿失手，下一个人就冲着那里来
- 赏是**谁杀了谁算**——骆也一样；猎人彼此提防，人心不齐

# 十一、碳的地下

- 碳的早就聚成一个地下组织，已成气候。矿上、窑上、煤场、锅炉房、铁铺后头的炭堆，
  哪一处烧的东西，都有他们的人先伸手探过
- 世人对碳的固有看法是"没出息"，所以从不关注、不警惕。**没出息的人，没人盯着**
- 借着"给燃料定等"这门被看不起的手艺，隐忍着，悄悄握住了一国的命脉
- 暗号：问"今年的炭，性子急还是闷？"答"外头闷，里头急。"
- 沿路有据点：如柳湾坡上的小窑（窑口老汉，缺两根指头），能补吃穿、补炭、治伤
- **学堂的雏形**：这个世界还没有"学校"。各家手艺都是师徒、父子口传。
  **当世只有碳的在暗中办**：一间屋子，教碳的孩子，用不同等级的炭做教具
- 石头被垄断，他们买不过人家，只能让每块石头换来更多进步——教得好，就是省石头

## 护送林砚的

  托起来容易，成形最难——他们能成形，是那间屋子教出来的。**不到要命的时候不露**，从窑洼到渡口一回没开过袋
  - 怕水：炭一沾水就沉、就散、就托不住。在别人的水边，他们的每一撮炭都要打折扣

# 十三、林砚的一个念头：合作

- 水是两个氢挂一个氧（H₂O），一斤水里氢才一两出头。摆弄氢的人去抓水，十分力九分拖着氧这个秤砣——所以蓑衣人宁可烧石头拆水
- 要是有人替他拎着那个秤砣：一个抓氢，一个抓氧，一瓢水就是一柄锤
- **"一个人拽不动的，几个人各拽一头。"** 这边的人没有这个念头：人人只练自己那一样，拿自己那一样去赢
- 这是全书"从个人解题走向共同探索"的第一粒种子

# 十四、朔安城与静先生

- 断崖峡以北。土夯包石的矮墙，城楼**没有皇家的旗**，门洞旧木匾"朔安"
- 皇家不认这座城：城里用烙"朔安"印的竹片；皇家的钱收了花不出去；城外东西进城要过皇家的卡；**盐从南边来，南边盐道皇家卡着**——盐一斤九枚（东边两枚）。**但没有皇家层层抽、没有氯的横行**：进城只抽一成修墙修渠，白面饼一枚两个（东边一枚一个黑面），日子反倒比东边好过
- 城里人叫他**"静先生"**（风停、声远——看得见的叫法）。住北城墙望楼旁两间旧屋，窗朝北
- **十一年前那一战**（第十五章）：秋天北风，城北三十里长岗上五十辆盐车、二十来个氯的，正当中穿一身黄的年轻人——**如今的大统领**。
  当场拆盐放雾，雾成一道东西天边的黄墙往南走。他在城北三里的洼边推气（不是推雾），与岗上推雾的拉锯，墙堆到城墙三个高，压了一炷香；
  对方伸出东西两条舌头绕两翼，他来回飞六趟顾不过来；最后飞过墙顶二十多里压住整道岗，二十来人醉坐；年轻的那个先一口气骑马跑了。
  他推散那道墙，后半夜东风把它送去**城西三十里的柳沟、上坡、下坡**。岗上拆剩的银白（钠）见露水自烧。
  从此氯的十一年没来——怕的是他能飞过墙顶。他们在想"怎么让他一个人顾不过来"
- **静先生也有价**：皇家挂了十一年，没人敢去领
- 他老了：十年前能压一炷香，如今二十息；再过几年十息（**二十息是他放出去的假数**）
- **一推一吃**（林砚提出）：他把雾推到一处、压住，炭在那儿等——**压得越紧，炭吃得越多**（林砚心里：那边书上说，吃多少看气压得多紧）
- **两只碗**试出来的：压着吃得多；**一松会吐**（吐一小半，剩的仍比不压的多）。所以压着吃、吃饱了压着送走、埋进坑里再松——**吃饱的炭不能留**
- **碳的手能量炭吃了多少**：吃得越饱越"闷"。不只林砚，祁也摸得出——碳的人人有这一双手
- 那人摆弄的是满天都有的那一样（林砚心里：氮），见第十一章起
- 样子：白发披肩不束，旧灰白布袍洗得发薄，握竹杖，**悬在离地一人多高的半空**；身边齐腰处浮一块**紫石**，尘土绕着它转成小漩涡（气托着，算"挨着"）
- 已见手段：一路减速（十来步外开始稠、越近越稠，停在身前一步）；声浪（地底般的嗡，草倒成圆，土浪比马快）；
  一线看不见的刀（切断骆的链、切开半人高石头，断面能照人）；推（推倒成墙的草，把人推飞十来步）；声音贴耳传话
- **大招·区域压制**：二十来息，圈子能铺到二三十步外；压完他膝软、喘、白发湿透；紫石压制时亮得像烧透的炭
- **真实上限**（第二十章）：整条大道三里连两边草地，压一炷香——**圈里两百人全死**；压完他是真累（手抖、喘、膝软、紫光比天黑时还淡，走不动了只能拄杖走）；能**一点一点松**（松得慢就不伤耳）；能把十来人连土托离地、把两百人的兵器用贴地风抽走、一线劈开包铁撞木
- 压制时**圈里的火全灭、火镰磕不着，磷也不亮**（帮烧的那一点被挤走）
- **压制的伤**：压着时耳胀、眼眶鼻梁后胀、胸口压痛、醉；**一松最伤人**——耳膜往外弹破流血、鼻血、肺里裂咳粉红沫、眩晕呕吐、眼白血丝破。离中心越近越重
- 短处：**压不死一直在原地转的东西**（慢一点、再催一点）；压制极耗、不能久；年老
- 手段：取之不尽；声浪、冲击波大范围压人；吸、推物体；让逼近的攻击一路减速到伤不了人；收成一线看不见的一刀
- **大招·区域压制**：把一整片的气压下去、压密。圈里尘土落得极慢、声音发闷，人如在水底；链甩不开、斧转不动、飞荡飞不起；
  圈里的人胸闷耳胀、**反应迟半拍，像喝醉了**（林砚心里：氮醉，那边潜水的人下深了会这样）。极耗石头，不能久压，压完他也喘

# 十五、朔安城的四面

**只有南面进得来大队人马；其余三面地势只容小股偷袭。**

- **南**：正面大道，直通断崖峡口，两边平地枯草，没遮没拦
- **北**：北墙根一道深沟（旧河道，烂泥），北门只一道一车宽的土埂跨沟；过沟是平地、洼、长岗；门洞外一道瓮城
- **东**：贴河，护城河绕东墙，一座两人并排都挤的窄石桥连东门，桥那头河滩
- **西**：陡碎石坡贴城墙根，西墙无门，要进得爬墙；城墙土夯包石
- 城里西墙根有炭场（管事姓韩，碳的，秃顶粗脖子），锅炉房
- 城里石头少：从北边运不进来；静先生库里只几块

- **骆的算盘（第十六至二十一章）**：拿两百来号人当炮灰堵南门、拖住静先生，自己绕到东墙专打林砚；赏不打算分。输在二十息是假的

# 十六、石头为什么要飞

- 石头全力出劲会烫，好石头烫到攥不住。强者让它飞，托在自己的元素里一直转、一直换
- 骆：三道铁环（铁经得住烫，转得慢）；静先生：气托、四周尘土慢转（气散了就换）
- **林砚：循环的炭**——贴石一层烧红即甩成火星，外头引新黑炭补进；一团黑往里裹、红往外翻的漩（第二十二章首用）

# 十七、最没出息的那一个（作者掌握）

- 只停在第二十三章林砚内心那一层（原文已定稿）。后续不展开、不出场、不写任何过程
- 林砚的护城河仍是那一个念头：他知道门朝哪边开，所以更不能说
- 林砚心里的"克制表"：每一样元素都有东西治它，这边几百年谁也没把谁吃干净

# 十八、看亲（第二十四章）

- 孩子满七岁由"看亲的"测：攥一片赤石，另一手悬过一溜小碗（铁屑、铜末、炭末、细砂、盐、清水、硫块；金箔碗加钱才揭），哪碗动就是哪样
- 一回两枚铜；测不出的叫"没亲"，镇上叫"空碗"
- 桌上只摆看得见、摸得着的东西——**桌上没有的，这边的人当作没有**（与"本地人按看得见的叫"同一个盲区）
- 桌子大小看地方：镇上摆常见的；县城多锡铅银油石灰草木灰；山里老看亲的见得多，摆朱砂、白矾、水银、骨粉、各色土
- 丁五（石埠镇码头挑夫）：三张桌子测了四年，一只碗没动；他娘十一年前死于大统领车队过石埠时随手放的一口雾和砸碎的鬼火罐（左臂烧穿，咳一冬，开春死）
